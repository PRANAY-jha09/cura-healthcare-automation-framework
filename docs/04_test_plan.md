# Test Plan

## Project Name

CURA Healthcare Automation Framework

---

## Objective

Verify that the CURA Healthcare application functions correctly for appointment booking and user authentication.

---

## Scope

### In Scope

- Login
- Book Appointment
- Appointment History
- Logout

### Out of Scope

- Backend APIs
- Database Validation
- Performance Testing
- Security Testing

---

## Test Types

- Functional Testing
- UI Testing
- Smoke Testing
- Regression Testing

---

## Test Environment

- Windows 11
- Google Chrome
- Python
- Selenium
- Pytest

---

## Entry Criteria

- Application is accessible
- Test data available

---

## Exit Criteria

- All critical test cases executed
- No Critical or High defects open
